## Applied Skills


### Cardiology Notes — Applied Skills

##### 12.1 Data Interpretation

###### ECG — the drill
Always present in the same order (Installment 1): **rate → rhythm → axis → P → PR → QRS → ST → T → QT**. Then pattern-recognise. High-yield patterns to spot in seconds:
- **ST elevation** in a territory → STEMI (name the leads and artery).
- **ST depression / T inversion** → ischaemia/NSTEMI.
- **Tall tented T waves** → hyperkalaemia.
- **Widespread saddle ST elevation + PR depression** → pericarditis.
- **Short PR + delta wave** → WPW.
- **Long QT** → torsades risk (drugs/electrolytes).
- **Dominant R in V1 + right axis** → RVH; **deep S in V1 + tall R in V5/6** → LVH.
- **AV dissociation** → complete heart block.

###### Other data
- **Troponin** — interpret as a *trend* with the clinical picture; a rise-and-fall + ischaemia = MI; a stable rise = injury (Installment 1).
- **BNP/NT-proBNP** — a normal value largely excludes HF.
- **CXR** — heart size, pulmonary oedema (ABCDE), effusions, mediastinal width, valve calcification, devices.
- **Echo report** — LVEF, wall motion, valves/gradients, chamber size, pericardium.
- **ABG in the crashing patient** — metabolic acidosis (lactate) in shock; type 1 respiratory failure in pulmonary oedema.

##### 12.2 OSCE Stations
- **Cardiovascular examination** — run the Installment 1 sequence smoothly; verbalise fluid status, JVP, apex, murmurs, and peripheral signs; offer to check obs, dip urine, ECG.
- **Focused murmur/JVP station** — time the murmur (systolic/diastolic), locate, use dynamic manoeuvres (RILE, Valsalva), and give the most likely lesion.
- **Device/anticoagulation counselling** — pacemaker/ICD basics; explaining DOAC vs warfarin, monitoring, and bleeding risk.
- **Counselling stations** — starting a statin (why, side effects, monitoring), AF anticoagulation (stroke vs bleeding trade-off), post-MI lifestyle and cardiac rehab, and breaking bad news in advanced heart failure (use a structured framework, e.g. SPIKES).
- **Prescribing stations** — the ACS bundle, acute pulmonary oedema, hyperkalaemia, and rate/rhythm control in AF.

##### 12.3 Emergency Scenarios — the protocols

###### Acute coronary syndrome (STEMI)
Recognise (ischaemic pain + ST elevation) → aspirin + P2Y12 + anticoagulation, analgesia, O₂ only if hypoxic → **reperfusion**: primary PCI if ≤120 min from diagnosis, else fibrinolysis <12 h (Installment 1).

###### Cardiac arrest / peri-arrest (Adult ALS)
- **Shockable (VF/pVT):** defibrillate → 2-min CPR cycles. **Adrenaline 1 mg** after the **3rd** shock (RCUK/ERC) — **note ANZCOR gives it after the 2nd shock** — then every 3–5 min; **amiodarone 300 mg** after the 3rd shock (150 mg after the 5th).
- **Non-shockable (PEA/asystole):** CPR + adrenaline 1 mg **as soon as possible**, then every 3–5 min.
- Treat **4 Hs & 4 Ts**.
- **Peri-arrest bradycardia** with adverse features: **atropine 500 µg IV** (repeat to 3 mg) → transcutaneous pacing / isoprenaline / adrenaline infusion → transvenous pacing.
- **Peri-arrest tachycardia** with adverse features (shock, syncope, ischaemia, HF): **synchronised DC cardioversion**.

###### Acute pulmonary oedema
Sit up, high-flow O₂ / **CPAP**, IV **loop diuretic**, IV **nitrate** if BP allows, treat the precipitant (**LMNOP**, Installment 2).

###### Cardiac tamponade
Beck's triad + pulsus paradoxus + echo (diastolic RV collapse) → **urgent pericardiocentesis**; IV fluids as a temporising measure.

###### Aortic dissection
Sudden tearing pain to the back + BP asymmetry + wide mediastinum → **CT angiogram** → control **HR then BP** (IV beta-blocker to HR ~60, systolic ~100–120) → **Type A: emergency surgery; Type B: medical**.

###### Hypertensive emergency
Severe hypertension **with acute end-organ damage** → controlled IV BP reduction (avoid precipitous drops) — *except dissection*, which needs rapid aggressive control.

###### Hyperkalaemia (a can't-miss cardiac emergency)
- **Severity:** mild 5.5–5.9 · moderate 6.0–6.4 · **severe ≥6.5 mmol/L, or any level with ECG changes**.
- **ECG evolution:** tall **tented T waves** → flattened/absent P → **broad QRS** → **sine wave** → VF/asystole.
- **Management (in order):**
  1. **Cardioprotection:** IV **calcium gluconate 10% 10 mL** (or calcium chloride) — stabilises the myocardium; does *not* lower K⁺; repeat if ECG changes persist.
  2. **Shift K⁺ into cells:** **insulin (10 units soluble) + 25 g glucose** IV (monitor for hypoglycaemia); **salbutamol** 10–20 mg nebulised.
  3. **Remove K⁺:** potassium binders (sodium zirconium cyclosilicate, patiromer) for ongoing control; **haemodialysis** if refractory or in renal failure.
  4. Stop K⁺-raising drugs (ACEi/ARB/MRA, K⁺ supplements) and treat the cause.

##### A. Emergency Drug/Number Recall

| Scenario | Key action / dose |
|---|---|
| Shockable arrest | Adrenaline 1 mg after 3rd shock (ANZCOR: 2nd); amiodarone 300 mg after 3rd shock |
| Non-shockable arrest | Adrenaline 1 mg ASAP, then every 3–5 min |
| Adverse bradycardia | Atropine 500 µg IV (max 3 mg) → pacing |
| Adverse tachycardia | Synchronised DC cardioversion |
| SVT (stable) | Vagal → adenosine 6→12→18 mg |
| Hyperkalaemia (cardioprotect) | Calcium gluconate 10% 10 mL IV |
| Hyperkalaemia (shift) | Insulin 10 U + 25 g glucose; salbutamol neb |
| Torsades | IV magnesium sulfate |
| STEMI reperfusion | PCI ≤120 min from diagnosis, else fibrinolysis <12 h |
| Dissection | IV β-blocker: HR ~60, SBP ~100–120 |

##### B. "See this → do this" (emergency ECG cues)

| ECG | Immediate thought |
|---|---|
| ST elevation in a territory | STEMI → reperfuse |
| Tall tented T waves | Hyperkalaemia → calcium + shift |
| Broad complex, regular, unwell | VT → cardiovert if unstable |
| Polymorphic VT, long QT | Torsades → magnesium |
| AV dissociation, bradycardia | Complete heart block → pace |
| Widespread saddle ST + PR depression | Pericarditis (not STEMI) |
