## Endocrine Physiology


### Endocrine Master Notes — Endocrine Physiology

#### 1.1 Principles of Hormone Action

Hormones fall into **three chemical classes**, and the class predicts almost everything about how the hormone behaves:

| Class | Examples | Storage | Transport | Receptor | Speed |
|---|---|---|---|---|---|
| **Peptide/protein** | Insulin, GH, PTH, ADH, most pituitary hormones | Pre-formed in vesicles | Dissolved (water-soluble) | **Cell-surface** | Fast (seconds–minutes) |
| **Steroid** | Cortisol, aldosterone, sex steroids, vitamin D | Made **on demand** (not stored) | Bound to carrier proteins (lipophilic) | **Intracellular/nuclear** | Slow (hours — needs gene transcription) |
| **Amine** | Thyroid hormones, catecholamines | Thyroid: stored in colloid; catecholamines: vesicles | Thyroid bound (TBG); catecholamines free | Thyroid = **nuclear**; catecholamines = **surface** | Thyroid slow; catecholamines fast |

**Discriminator:** thyroid hormone is an amine but behaves like a **steroid** (lipophilic, carrier-bound, **nuclear receptor**, slow genomic action). Catecholamines are amines that behave like **peptides** (surface receptor, fast). *Memory: the receptor location tells you the speed — surface = fast/second-messenger, nuclear = slow/gene transcription.*

**Second-messenger systems** (surface receptors):
- **cAMP (Gs)** — ACTH, LH/FSH, TSH, PTH, glucagon, ADH (V2), β-adrenergic. *Memory: "FLAT ChAMP" hormones use cAMP.*
- **IP₃/DAG (Gq)** — GnRH, TRH, ADH (V1), angiotensin II, α₁-adrenergic. *Memory: "GGOAT" → the ones that raise intracellular calcium.*
- **Receptor tyrosine kinase** — **insulin**, IGF-1 (also growth factors).
- **JAK/STAT** — GH, prolactin, leptin, cytokines.

#### 1.2 The Hypothalamic–Pituitary Axis

The **hypothalamus** releases factors into the hypophyseal **portal system** to control the **anterior pituitary**, which in turn drives peripheral endocrine glands. The **posterior pituitary** is different — it is neural tissue storing hormones made in the hypothalamus.

| Hypothalamic factor | Anterior pituitary hormone | Target/effect |
|---|---|---|
| GHRH (+) / somatostatin (−) | **GH** | Liver IGF-1, growth, metabolism |
| TRH (+) | **TSH** (also stimulates prolactin) | Thyroid → T4/T3 |
| CRH (+) | **ACTH** | Adrenal cortex → cortisol |
| GnRH (+, pulsatile) | **LH/FSH** | Gonads → sex steroids, gametes |
| **Dopamine (−, tonic)** | **Prolactin** | Lactation |

**Two high-yield consequences of this wiring:**
- **Prolactin is under tonic *inhibition* by dopamine.** Anything that removes dopamine (stalk compression by a pituitary mass, dopamine-antagonist drugs like antipsychotics/metoclopramide) → **hyperprolactinaemia**. *This is why a big non-functioning pituitary tumour can still raise prolactin — the "stalk effect."*
- **TRH stimulates prolactin too**, so **primary hypothyroidism (high TRH)** can cause a modestly raised prolactin.

**Posterior pituitary** stores/releases two hypothalamic hormones:
- **ADH (vasopressin)** — from supraoptic/paraventricular nuclei; acts on renal collecting-duct **V2 receptors** (aquaporin-2 insertion → water reabsorption) and vascular **V1** (vasoconstriction).
- **Oxytocin** — uterine contraction, milk ejection.

#### 1.3 Metabolic and Glucose Physiology

**Insulin vs glucagon** — the fed/fasted switch:

| | Insulin (fed) | Glucagon (fasted) |
|---|---|---|
| Source | β cells (islet) | α cells |
| Trigger | ↑glucose, incretins (GLP-1/GIP) | ↓glucose |
| Net effect | **Anabolic** — glycogenesis, lipogenesis, protein synthesis; drives K⁺ **into** cells | **Catabolic** — glycogenolysis, gluconeogenesis, ketogenesis |

**Counter-regulatory (stress/hyperglycaemic) hormones:** glucagon, **cortisol, growth hormone, adrenaline**. They all oppose insulin — which is why **stress, steroids and infection worsen glycaemic control** and can precipitate DKA/HHS.

**Calcium homeostasis** — the three-organ loop (learn this cold, it explains every calcium disorder):

| Hormone | Source | Bone | Kidney | Gut | Net serum Ca²⁺ |
|---|---|---|---|---|---|
| **PTH** | Parathyroids (low Ca²⁺ trigger) | ↑resorption | ↑Ca²⁺ reabsorption, ↑phosphate excretion, **↑1α-hydroxylase** | ↑ (indirectly via vit D) | **↑** (↓ phosphate) |
| **1,25-vitamin D (calcitriol)** | Skin→liver→kidney activation | ↑resorption (permissive) | ↑Ca²⁺ + phosphate reabsorption | **↑Ca²⁺ + phosphate absorption** | **↑** (↑ phosphate) |
| **Calcitonin** | Thyroid C-cells | ↓resorption | ↑excretion | — | ↓ (minor in humans) |

**Discriminator:** **PTH raises calcium but *lowers* phosphate**; **vitamin D raises both**. This phosphate split is how you read the calcium panel (see Section 6). Vitamin D activation: skin (7-dehydrocholesterol → cholecalciferol) → **liver (25-hydroxylation)** → **kidney (1α-hydroxylation, PTH-driven)** to active **1,25-(OH)₂-D**.

**Cortisol** (glucocorticoid) actions: ↑gluconeogenesis and insulin resistance (**diabetogenic**), protein catabolism, immunosuppression/anti-inflammatory, permissive for catecholamine vascular tone (why cortisol deficiency → shock), ↑appetite, mineralocorticoid effect at high levels. Secreted with a **diurnal rhythm** (peak ~waking, trough ~midnight) — the basis of **midnight/late-night cortisol testing**.

**RAAS:** ↓renal perfusion/↓Na⁺ → **renin** (JG cells) → angiotensinogen → **angiotensin I** → (ACE, lung) → **angiotensin II** (vasoconstriction + ↑aldosterone). **Aldosterone** (zona glomerulosa) → renal Na⁺ retention and **K⁺/H⁺ excretion** → this is why aldosterone excess causes **hypertension + hypokalaemia + metabolic alkalosis**, and deficiency causes the reverse.

#### 1.4 Dynamic Testing Logic

One rule governs every endocrine dynamic test:

> **Suspect excess → try to SUPPRESS it (a normal axis suppresses; autonomous secretion does not).**
> **Suspect deficiency → try to STIMULATE it (a normal axis responds; a failed gland does not).**

| Suspected problem | Test | Normal (excludes disease) |
|---|---|---|
| Cushing's (cortisol **excess**) | **Dexamethasone suppression** | Cortisol suppresses |
| Acromegaly (GH **excess**) | **OGTT** (glucose should suppress GH) | GH suppresses <1 µg/L |
| Conn's (aldosterone **excess**) | Saline/fludrocortisone **suppression** | Aldosterone suppresses |
| Adrenal insufficiency (**deficiency**) | **Short Synacthen** (ACTH stimulation) | Cortisol rises |
| GH/ACTH reserve (**deficiency**) | Insulin tolerance test | GH/cortisol rise to hypoglycaemia |
| Diabetes insipidus (ADH **deficiency/resistance**) | **Water deprivation** ± desmopressin | Urine concentrates |

#### Rapid-Recall Discriminators — Section 1

| Clue / question | Answer |
|---|---|
| Steroid vs peptide receptor location | Steroid = **intracellular/nuclear**; peptide = **cell-surface** |
| Amine that acts like a steroid | **Thyroid hormone** (nuclear, carrier-bound, slow) |
| Insulin receptor type | **Receptor tyrosine kinase** |
| GH & prolactin signal via | **JAK/STAT** |
| Prolactin's dominant control | **Tonic inhibition by dopamine** |
| Why a pituitary mass raises prolactin | Stalk effect (loss of dopamine inhibition) |
| PTH effect on phosphate | **Lowers** it (raises calcium) |
| Vitamin D effect on phosphate | **Raises** it (raises calcium) |
| Final activation step of vitamin D | **1α-hydroxylation in the kidney** (PTH-driven) |
| Aldosterone excess electrolyte triad | ↑BP, **↓K⁺, metabolic alkalosis** |
| Counter-regulatory hormones | Glucagon, cortisol, GH, adrenaline |
| Suspect hormone **excess** → which test? | **Suppression** |
| Suspect hormone **deficiency** → which test? | **Stimulation** |
