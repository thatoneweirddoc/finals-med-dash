## Primary Immunodeficiency — Pattern Recognition


### Immunology & Allergy Master Notes — Primary Immunodeficiency — Pattern Recognition

The exam skill is **inferring the defective arm of the immune system from the infection pattern**, not memorising rare syndromes.

| Defect | Infection pattern — the giveaway | Typical age at presentation | Named examples |
|---|---|---|---|
| **B-cell / antibody (humoral)** | Recurrent **sinopulmonary** infection with **encapsulated** bacteria (*S. pneumoniae*, *H. influenzae*), giardia; enteroviral infections | **After ~6 months** (once maternal IgG wanes) — the timing is the clue | X-linked (Bruton's) agammaglobulinaemia (male, absent B cells, no tonsils/nodes), **CVID** (later onset, autoimmunity and lymphoma risk), **selective IgA deficiency** (commonest primary immunodeficiency; often asymptomatic; ⚑ **anaphylaxis to blood products containing IgA**) |
| **T-cell / cellular** | **Opportunistic and intracellular** infection — PCP, CMV, persistent candidiasis, disseminated BCG/mycobacteria, chronic viral illness; failure to thrive | Early infancy | **DiGeorge** (22q11 deletion) — thymic hypoplasia, hypocalcaemia/tetany, cardiac outflow defects, dysmorphism ("CATCH-22"); **SCID** (both arms — a paediatric emergency) |
| **Phagocyte** | Recurrent **skin and deep abscesses**, poor wound healing, **catalase-positive** organisms (*S. aureus*, *Serratia*, *Aspergillus*, *Burkholderia*) | Early childhood | **Chronic granulomatous disease** (NADPH oxidase defect — ⚑ diagnosed with the **dihydrorhodamine (DHR)** flow cytometry test, historically NBT); **leucocyte adhesion deficiency** (delayed umbilical cord separation, no pus formation) |
| **Complement** | Recurrent ***Neisseria*** infection (meningococcal/gonococcal) with terminal pathway defects; early classical-pathway (C1–C4) deficiency → **SLE-like disease** | Any age | Terminal complement (C5–C9) deficiency; **C1 esterase inhibitor deficiency → hereditary angioedema** |

**Hereditary angioedema — the anaphylaxis mimic worth separating out:** C1 esterase inhibitor deficiency → **bradykinin-mediated** angioedema. **Non-pruritic, non-urticarial** swelling (often facial, laryngeal or abdominal), frequently with a family history, triggered by trauma/dental work or **ACE inhibitors**, and — critically — **does not respond to adrenaline, steroids or antihistamines**. Treatment is **C1-inhibitor concentrate or icatibant** (bradykinin B2 antagonist). **Discriminator:** urticaria and itch point to histamine/anaphylaxis; their absence with recurrent episodic swelling points to bradykinin-mediated angioedema.

**Secondary (acquired) immunodeficiency is far commoner than primary:** HIV, malignancy (especially haematological), iatrogenic (chemotherapy, steroids, biologics, rituximab-induced hypogammaglobulinaemia), malnutrition, splenectomy, chronic renal/liver disease, ageing. **In an adult with recurrent infection, think acquired first.**

**When to investigate for primary immunodeficiency — "SPUR":** **S**evere, **P**ersistent, **U**nusual (opportunistic organism/site), or **R**ecurrent infections; plus failure to thrive, family history, or unexplained autoimmunity. **First-line tests:** FBC with differential (lymphopenia, neutropenia), serum immunoglobulins (IgG/A/M), vaccine-response antibody titres, complement (C3/C4, CH50), HIV test, lymphocyte subsets.

#### Rapid-Recall Discriminators

| Clue / question | Answer |
|---|---|
| Lymph node zone housing B cells / T cells | Follicle (B) / paracortex (T) |
| Right lymphatic duct drains | Right side of the body above the diaphragm |
| Blood film after splenectomy | Howell–Jolly bodies (± target cells, thrombocytosis) |
| Organisms feared post-splenectomy | Encapsulated — pneumococcus, Hib, meningococcus |
| Thymoma association | Myasthenia gravis (and SVC obstruction) |
| Hypersensitivity mnemonic | ACID — Allergic, Cytotoxic, Immune complex, Delayed |
| Type I mechanism and timing | IgE mast cell degranulation, minutes |
| Type II vs Type III discriminator | Type II antigen is cell-bound; Type III antigen is soluble (complexes deposit) |
| Type IV timing and mechanism | 48–72 hours, T-cell mediated, no antibody |
| Contact dermatitis / Mantoux test type | Type IV |
| ABO haemolytic transfusion reaction type | Type II |
| Serum sickness / post-strep GN type | Type III |
| Skin prick vs patch testing | Prick = immediate/IgE (I); patch = delayed (IV) |
| First and most important drug in anaphylaxis | IM adrenaline, anterolateral thigh |
| Adult IM adrenaline dose | 500 micrograms of 1:1000 |
| Repeat adrenaline interval | 5 minutes if A/B/C problems persist |
| Positioning in anaphylaxis ⚑ | Lie flat (legs up if hypotensive); never stand the patient up |
| Skin changes absent in what proportion ⚑ | 10–20% — absence doesn't exclude anaphylaxis |
| Steroids in acute anaphylaxis ⚑ | No longer routinely recommended |
| Observation if 2 doses of adrenaline needed | 6 hours |
| Observation if >2 doses / severe asthma ⚑ | 12 hours |
| Confirmatory blood test after anaphylaxis | Serum mast cell tryptase (+ baseline ≥24 h later) |
| Rate of biphasic reactions | ~5% |
| Most effective single agent in allergic rhinitis | Intranasal corticosteroid |
| Eczema distribution: infant vs child | Face/extensors (infant) → flexures (child) |
| Gene implicated in eczema barrier defect ⚑ | Filaggrin |
| Painful punched-out vesicles on eczema + unwell | Eczema herpeticum → systemic aciclovir |
| Recurrent encapsulated sinopulmonary infection after 6 months | B-cell/antibody defect (e.g. Bruton's) |
| PCP, CMV, candidiasis, failure to thrive in infancy | T-cell defect (DiGeorge/SCID) |
| Hypocalcaemia + cardiac defect + thymic hypoplasia | DiGeorge (22q11) |
| Recurrent abscesses, catalase-positive organisms | Chronic granulomatous disease (DHR test ⚑) |
| Delayed umbilical cord separation, no pus | Leucocyte adhesion deficiency |
| Recurrent *Neisseria* infection | Terminal complement (C5–C9) deficiency |
| Commonest primary immunodeficiency | Selective IgA deficiency (⚑ anaphylaxis to IgA-containing blood products) |
| Non-itchy, non-urticarial recurrent swelling unresponsive to adrenaline | Hereditary angioedema (C1 inhibitor deficiency) → C1-INH concentrate/icatibant |
| Screening mnemonic for immunodeficiency | SPUR — Severe, Persistent, Unusual, Recurrent |

### Rheumatology & Immunology (ANU) — Immunodeficiency — Primary Immunodeficiency — Pattern Recognition

- TYPES: congenital or acquired (infection, malnutrition, aging, malignancy, iatrogenic e.g. chemo)
- EPIDEMIOLOGY: individual deficiencies are rare

Arthocentesis

- DIAGNOSTIC: determine cause of pain or swelling in the joint
- THERAPEUTIC: removal of excess fluid may help lessen pain and improve antibiotic
- SYNOVIAL FLUID CHARACTERISTIC:
- Crystals: gout (urate), pseudogout (pyrophosphate)
- WCC: bacterial septic; may be slightly elevated in RA, psoaritic and reactive arthritis
- Blood: hemarthrosis from trauma or fracture
- Fat: fracture
- Non-inflammatory: OA

Hypersensivity

- HYPERSENSITIVITY: the immune system, which normally serves a protective role, has a harmful effect. The hypersensitivity reactions can be memorized with the mnemonic ACID: A – Allergic/Anaphylactic/Atopic (Type I); C – Cytotoxic (Type II); I – Immune complex deposition (Type III); D – Delayed (Type IV)
- ALLERGY: abnormal immunological response to an otherwise harmless environmental stimulus
- AUTOIMMUNITY: abnormal immunological response directed against an antigen that is actually part of the body itself
