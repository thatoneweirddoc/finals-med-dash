## Respiratory Pharmacology & Prescribing


### Respiratory Master Notes — Respiratory Pharmacology & Prescribing

##### 11.1 Inhaled Therapies

The core inhaler classes (know target, onset, and the key adverse effect):

| Class | Examples | Action | Key adverse effect |
|---|---|---|---|
| **SABA** | Salbutamol | Short-acting β₂-agonist (bronchodilate) | Tremor, tachycardia, **hypokalaemia**, lactate |
| **LABA** | Salmeterol, formoterol | Long-acting β₂-agonist | As SABA; **never as monotherapy in asthma** (mortality risk) ⚑ |
| **SAMA** | Ipratropium | Short-acting antimuscarinic | Dry mouth, urinary retention, glaucoma (nebulised) |
| **LAMA** | Tiotropium, glycopyrronium | Long-acting antimuscarinic | Dry mouth; caution in prostatism/glaucoma |
| **ICS** | Beclometasone, budesonide, fluticasone | Inhaled corticosteroid (anti-inflammatory) | **Oral candidiasis, dysphonia** (rinse mouth), pneumonia risk in COPD |

**Combination inhalers** reduce inhaler burden: **ICS–formoterol** is now central to asthma (**AIR/MART** — reliever *and* maintenance); **LABA–LAMA** is the COPD backbone (± ICS, eosinophil-guided). **Device/technique** is examinable: check inhaler technique at every review; use **spacers** with pMDIs; consider dry-powder devices where inspiratory flow is adequate.

**Biologics for severe (type 2/eosinophilic) asthma** ⚑: **anti-IgE (omalizumab)**; **anti-IL-5/5R (mepolizumab, benralizumab, reslizumab)**; **anti-IL-4/13 (dupilumab)** — for uncontrolled severe asthma despite high-dose ICS-LABA, guided by IgE/eosinophils/FeNO.

##### 11.2 Other Respiratory Drugs

- **Oral corticosteroids** (prednisolone) — exacerbations and maintenance in severe disease; watch the long-term burden (osteoporosis, diabetes, adrenal suppression — don't stop abruptly).
- **Theophylline/aminophylline** — methylxanthine bronchodilator; **narrow therapeutic index** → nausea, arrhythmia, seizures; **levels rise with enzyme inhibitors** (macrolides, ciprofloxacin, cimetidine) and fall with inducers (smoking, rifampicin). Monitor levels.
- **Leukotriene receptor antagonists** (montelukast) — add-on in asthma; note neuropsychiatric warnings.
- **Antifibrotics** (pirfenidone, nintedanib) — slow FVC decline in IPF/progressive fibrosing ILD (Section 5).
- **CFTR modulators** (elexacaftor/tezacaftor/ivacaftor) — transformative in eligible CF (Section 4).
- **Mucolytics** — carbocisteine; **dornase alfa/hypertonic saline** in CF.
- **PAH-targeted drugs** — endothelin antagonists, PDE-5 inhibitors, prostacyclins, riociguat (Section 6).
- **Oxygen** — prescribe with a **target saturation range**; it is a drug with a therapeutic window.
- **Smoking cessation** — behavioural support + **NRT / varenicline / bupropion**; the single highest-value intervention across respiratory medicine.

##### 11.3 Prescribing and Safety

- **Antibiotics** — match to setting/severity (Section 7); remember **atypicals need a macrolide/tetracycline/quinolone**, and structural lung disease needs antipseudomonal cover.
- **Anti-tuberculous toxicities** (Section 7): rifampicin (orange, inducer, hepatitis), isoniazid (neuropathy → B6, hepatitis), pyrazinamide (hepatitis, gout), ethambutol (optic neuritis).
- **Drug-induced lung disease** — the four to name: **amiodarone, methotrexate, nitrofurantoin, bleomycin** (pulmonary fibrosis/pneumonitis); plus **β-blockers** (bronchospasm — caution in asthma), **ACE inhibitors** (dry cough), **NSAIDs/aspirin** (AERD), and **checkpoint-inhibitor pneumonitis**.
- **Counselling points** — inhaler technique + spacer; **rinse mouth after ICS**; carry the reliever; asthma action plan; steroid card for long-term/high-dose steroids; smoking cessation at every contact.

##### Part A — By Presenting Syndrome

###### A1. Breathlessness (acute)
Scan for the discriminator, then confirm:

| If you also see… | Think | Clincher |
|---|---|---|
| Pleuritic pain + haemoptysis + risk factors, clear-ish CXR, low CO₂ | **PE** | CTPA; type 1 failure with respiratory alkalosis |
| Wheeze, known asthma, PEF ↓ | **Acute asthma** | PEF %; **normal/rising CO₂ = life-threatening** |
| Smoker, purulent sputum, prior COPD | **AECOPD** | ABG: ↑CO₂, pH <7.35 → NIV |
| Fever, focal crackles, consolidation | **Pneumonia** | CURB-65, CXR |
| Sudden, pleuritic, tall thin (or COPD) | **Pneumothorax** | absent breath sounds, hyper-resonant; trachea away = tension |
| Orthopnoea, raised JVP, bibasal crackles, pink froth | **Pulmonary oedema (cardiac)** | ↑NT-proBNP, CXR bat-wing; CPAP |
| Stridor (inspiratory) | **Upper-airway obstruction** | emergency — secure airway |

###### A2. Breathlessness (chronic/progressive)
- **Obstructive** picture (wheeze, ↓FEV₁/FVC): asthma (variable, reversible, ↑FeNO) vs COPD (smoker, fixed, ↓DLCO) vs bronchiectasis (copious sputum, HRCT signet-ring).
- **Restrictive** picture (velcro crackles, clubbing, ↓DLCO): **ILD/IPF** — then use zone (upper = CHARTS; lower = IPF/CTD/asbestos).
- **Isolated low DLCO, clear lungs**: pulmonary vascular disease (**PAH/CTEPH**) or anaemia.

###### A3. Haemoptysis
| Clue | Diagnosis |
|---|---|
| Weight loss, smoker, mass/collapse on CXR | **Lung cancer** |
| Night sweats, apical cavitation, risk factors | **TB** |
| Pleuritic pain, tachycardia, risk factors | **PE** |
| Copious daily purulent sputum, HRCT signet-ring | **Bronchiectasis** |
| Fungus ball in an old cavity | **Aspergilloma** |
| Haematuria + haemoptysis (pulmonary–renal) | **Goodpasture / ANCA vasculitis** |
| Massive volume, systemic-pressure bleed | **Bronchial artery** source → embolisation |

###### A4. Chronic cough (>8 weeks)
The "big three" (asthma, GORD, upper-airway/post-nasal drip) + **ACE-inhibitor** cough; always exclude **cancer/TB** in a smoker, and **ILD** if velcro crackles. Dry + fibrosis → ILD; productive daily → bronchiectasis/COPD.

###### A5. Pleuritic chest pain
PE, pneumonia, pneumothorax, pericarditis (positional/ECG), musculoskeletal, and (with effusion) malignancy/TB. The **ECG + CXR + troponin/D-dimer** triage separates the emergencies.

###### A6. The abnormal CXR (localise first)
Consolidation (air bronchogram) vs collapse (volume loss, shift *towards*) vs effusion (meniscus, shift *away*) vs pneumothorax (lung edge) vs mass (cancer) vs bilateral reticulation (ILD) vs BHL (sarcoid/lymphoma/TB).

##### Part C — Confusable Pairs *(reduced to the one separating feature)*

| Pair | The single separating feature |
|---|---|
| **Asthma vs COPD** | Asthma = **reversible**, normal/high DLCO, atopy; COPD = fixed, **low DLCO**, smoker |
| **Consolidation vs effusion** (both dull bases) | Consolidation = **increased** vocal resonance + bronchial breathing; effusion = **reduced** |
| **Collapse vs effusion** (mediastinal shift) | Collapse pulls **towards**; large effusion pushes **away** |
| **Transudate vs exudate** | **Light's criteria** (any one positive = exudate) |
| **Type 1 vs type 2 failure** | Type 2 has **↑CO₂** |
| **Acute vs chronic type 2 failure** | Bicarbonate — **high HCO₃⁻ = chronic** (renal compensation) |
| **UIP (IPF) vs NSIP** | UIP = honeycombing, steroids harmful; NSIP = ground-glass, CTD, **steroid-responsive** |
| **CPAP vs BiPAP** | CPAP = oxygenation (type 1, oedema); **BiPAP = CO₂ clearance** (type 2, AECOPD) |
| **Primary vs secondary pneumothorax** | Secondary = **underlying lung disease** (lower threshold to drain) |
| **Tension vs simple pneumothorax** | Tension = **haemodynamic compromise + trachea deviated away** (treat before imaging) |
| **Small-cell vs NSCLC** | SCLC = neuroendocrine paraneoplastic (SIADH/ACTH/LEMS), chemo not surgery |
| **Squamous vs small-cell hypercalcaemia** | **Squamous = PTHrP hypercalcaemia**; small-cell = SIADH/ACTH |
| **Aspergilloma vs ABPA vs invasive aspergillosis** | Old cavity (fungus ball) vs **asthmatic + ↑IgE/central bronchiectasis** vs immunocompromised angioinvasion |
| **Pleural plaques vs asbestosis vs mesothelioma** | Exposure marker (benign) vs the **fibrosis** vs the **malignancy** |
| **Bartter-style renal loss is renal, not respiratory** — don't cross-wire | (trap) |
| **Legionella vs Mycoplasma** | Legionella = hyponatraemia + deranged LFTs + diarrhoea; Mycoplasma = cold agglutinins + erythema multiforme |
| **mMRC (symptoms) vs CURB-65 (pneumonia severity) vs CHA₂DS₂ (AF)** | Match the score to the disease |
