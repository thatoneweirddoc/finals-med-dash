## Renal Syndrome Recognition and Lookup Tables

### Finals-study-2.pdf — Part A: Recognition by Presenting Syndrome (pages 94-97)

###### Renal Disease Recognition — Formulation

###### & Quick-Spot Summary

A synthesis of the section notes, organised for **pattern recognition:** meet the disease by its presenting syndrome, clinch it with the single differentiating feature. Everything here is cross-checked in the parent section files. Use it as the night-before flick-through.

###### How to use this document

- **Part A** — organised by presenting syndrome (how the patient actually turns up). Find the syndrome, scan the discriminators.
- **Part B** — signature tables: the fastest single-clue lookups (pathognomonic clue, antibody, complement, casts, IF pattern, biochemistry).
- **Part C** — confusable pairs: the head-to-heads students mix up, and the one feature that separates each.

#### A1. Acute kidney injury — which bucket?

###### First split: pre-renal / intrinsic / post-renal

| Bucket | Points towards it | Clinching feature |
| --- | --- | --- |
| Pre-renal | Hypovolaemia, sepsis, HF, cirrhosis, NSAID/ACEi | FeNa <1%, urine osm >500, bland urine, high urea:creatinine; responds to fluid |
| Intrinsic (ATN) | Prolonged pre-renal/toxins/contrast | FeNa >1–2%, urine osm ~300, muddy-brown casts; no response to fluid |
| Post-renal | Older man, single kidney, pelvic malignancy | Hydronephrosis on US; relieved by catheter/nephrostomy |

###### Then the specific AKI syndromes — each has a one-line tell:

| Syndrome | The clue that clinches it |
| --- | --- |
| Rhabdomyolysis | Dipstick blood +++, no RBCs on microscopy; ↑↑CK, ↑K⁺/PO₄³⁻, ↓Ca²⁺ |
| Tumour lysis syndrome | Post-chemo; ↑K⁺, ↑PO₄³⁻, ↑urate, ↓Ca²⁺ ("everything up except calcium") |
| Contrast-associated AKI | Creatinine rises 48–72 h after contrast, recovers |
| Hepatorenal syndrome | Cirrhosis + AKI + urine Na <10 + no response to albumin; bland urine |
| Cholesterol emboli | Post-angiogram + livedo reticularis + eosinophilia + low complement |
| Acute interstitial nephritis | New drug (PPI/NSAID/penicillin) + sterile pyuria + white cell casts ± eosinophilia |
| Scleroderma renal crisis | Systemic sclerosis + severe HTN + AKI + MAHA → give ACE inhibitor |
| Pulmonary–renal syndrome | Haemoptysis + RPGN → anti-GBM or ANCA vasculitis (urgent) |

#### A2. Nephrotic syndrome (heavy protein, low albumin, oedema)

| Disease | Differentiating feature |
| --- | --- |
| Minimal change disease | Child, steroid-responsive; EM foot-process effacement, normal LM/IF |
| FSGS | Adult (esp. Black patients); secondary to HIV/obesity/reflux/sickle; often steroid-resistant |
| Membranous nephropathy | Older White adult; anti-PLA2R +ve; subepithelial deposits/"spikes"; renal vein thrombosis risk; malignancy/SLE/HepB secondary |
| Diabetic nephropathy | Long-standing diabetes + retinopathy; Kimmelstiel–Wilson nodules; bland sediment |
| Amyloidosis | Older; myeloma/chronic inflammation; Congo red apple-green birefringence |

#### A3. Nephritic syndrome (haematuria, RBC casts, HTN, ↓GFR)

| Disease | Differentiating feature | Complement |
| --- | --- | --- |
| IgA nephropathy | Visible haematuria during a URTI (synpharyngitic, 1–2 days) | Normal |
| Post-streptococcal GN | Haematuria 1–2 weeks after throat/skin infection; ↑ASOT | Low C3 |
| Anti-GBM (Goodpasture) | Haemoptysis + RPGN; linear IgG | Normal |
| ANCA vasculitis | GPA (sinus/lung, c-ANCA/PR3), MPA (p-ANCA/MPO), EGPA (asthma+eosinophilia) | Normal |
| Lupus nephritis | Young woman, multisystem, ANA/dsDNA; "full house" IF | Low C3 AND C4 |
| MPGN / C3 glomerulopathy | Mixed nephrotic/nephritic; "tram-track" GBM | Low C3 |
| Cryoglobulinaemia | Hepatitis C + purpura + arthralgia + neuropathy | Low C4 |
| IgA vasculitis (HSP) | Child: palpable purpura (buttocks/legs) + abdo pain + arthralgia + nephritis | Normal |

#### A4. Rapidly progressive GN (crescentic — an emergency)

Group by immunofluorescence — this is the whole diagnostic move:
- **Linear IF** → **anti-GBM disease**
- **Granular IF** → **immune-complex** (lupus, IgA, post-infectious)
- **Pauci-immune (scanty) IF** → **ANCA vasculitis**

#### A5. Isolated haematuria (no/low protein, preserved function)

| Disease | Differentiating feature |
| --- | --- |
| Thin basement membrane disease | Persistent isolated haematuria, benign, family history, normal function |
| Alport syndrome | Haematuria + sensorineural deafness + ocular (lenticonus) + progressive failure; usually X-linked |
| Urological (malignancy/stone) | Isomorphic RBCs, clots, no casts; painless visible haematuria in older smoker = cancer until excluded |

#### A6. Tubular & inherited electrolyte syndromes

###### Renal tubular acidoses (all = normal anion gap metabolic acidosis):

| Type | K⁺ | Urine pH | The tell |
| --- | --- | --- | --- |
| 1 (distal) | Low | >5.5 | Can't acidify urine; stones/nephrocalcinosis |
| 2 (proximal) | Low | Variable/<5.5 | Fanconi features (glycosuria, phosphaturia) |
| 4 (hypoaldosteronism) | High | <5.5 | Diabetic; the only hyperkalaemic RTA |

###### Inherited tubulopathies (all hypokalaemic metabolic alkalosis):

| Disorder | BP | Urine Ca²⁺ | The tell |
| --- | --- | --- | --- |
| Bartter | Normal/low | High | "Loop-diuretic-like" (NKCC2); presents young |
| Gitelman | Normal/low | Low | "Thiazide-like" (NCC) + hypomagnesaemia; milder/older |
| Liddle | HIGH | — | Low renin & aldosterone; responds to amiloride not spironolactone |

#### B1. The single pathognomonic clue → diagnosis (master recognition table)

| If you see… | Think… |
| --- | --- |
| Dipstick blood +ve, no RBCs on microscopy | Rhabdomyolysis (or haemolysis) |
| Dipstick protein −ve but heavy proteinuria on PCR | Myeloma / light chains |
| Red cell casts + dysmorphic RBCs | Glomerulonephritis |
| Muddy-brown granular casts | ATN |
| White cell casts + sterile pyuria | AIN / pyelonephritis |
| Everything up except calcium, post-chemo | Tumour lysis syndrome |
| Glycosuria with normal blood glucose | Proximal tubular dysfunction (Fanconi / SGLT2i) |
| Envelope-shaped oxalate crystals + high anion + osmolar gap | Ethylene glycol |
| Kimmelstiel–Wilson nodules | Diabetic nephropathy |
| Apple-green birefringence (Congo red) | Amyloidosis |
| "Tram-track" GBM double contour | MPGN |
| Basket-weave GBM on EM | Alport syndrome |
| Palpable purpura on buttocks/legs in a child | IgA vasculitis (HSP) |
| Delayed quadriparesis after fast Na⁺ correction | Osmotic demyelination |
| Tall tented T waves | Hyperkalaemia |

#### B2. Antibody / serology → disease

| Antibody / marker | Disease |
| --- | --- |
| Anti-PLA2R | Primary membranous nephropathy |
| Anti-dsDNA / ANA, "full house" | Lupus nephritis |
| c-ANCA / anti-PR3 | GPA (granulomatosis with polyangiitis) |
| p-ANCA / anti-MPO | MPA, EGPA |
| Anti-GBM | Goodpasture |
| ↑ASOT / anti-DNase B | Post-streptococcal GN |
| Cryoglobulins (+ HepC) | Cryoglobulinaemic GN |
| Low ADAMTS13 | TTP |
| Serum free light chains / paraprotein | Myeloma |

#### B3. The complement split (fast SBA cracker)

- **Low C3 only:** post-streptococcal GN, C3 glomerulopathy/MPGN
- **Low C3 AND C4:** lupus nephritis, cryoglobulinaemia
- **Normal complement:** IgA nephropathy, anti-GBM, ANCA vasculitis, thin BM disease,

Alport

#### B4. Casts & urinalysis signatures

| Finding | Meaning |
| --- | --- |
| Red cell casts + dysmorphic RBCs | Glomerulonephritis |
| Muddy-brown granular casts | ATN |
| White cell casts | AIN / pyelonephritis |
| Fatty casts / "Maltese cross" | Nephrotic syndrome |
| Broad waxy casts | Chronic kidney disease |
| Hyaline casts | Non-specific (dehydration, normal) |

#### B5. Immunofluorescence patterns

| IF pattern | Disease |
| --- | --- |
| Linear IgG | Anti-GBM |
| Granular ("lumpy-bumpy") | Immune complex (post-strep, lupus) |
| Mesangial IgA | IgA nephropathy / HSP |
| "Full house" (IgG/A/M, C3, C1q) | Lupus nephritis |
| Pauci-immune (scanty) | ANCA vasculitis |

#### B6. Biochemical pattern signatures

| Pattern | Diagnosis |
| --- | --- |
| ↑K⁺, ↑PO₄³⁻, ↑urate, ↓Ca²⁺ (post-chemo) | Tumour lysis syndrome |
| ↑↑CK, ↑K⁺, ↑PO₄³⁻, ↓Ca²⁺ early → ↑Ca²⁺ late | Rhabdomyolysis |
| ↑PO₄³⁻, ↓Ca²⁺, ↑PTH, ↓calcitriol | CKD–MBD (opposite of primary hyperPTH) |
| Normal anion gap acidosis + hyperkalaemia + diabetic | Type 4 RTA |
| Hypokalaemic metabolic alkalosis + normal BP | Bartter / Gitelman (or diuretic/vomiting) |

#### B7. Eponyms & buzzwords → diagnosis

| Buzzword | Diagnosis |
| --- | --- |
| Kimmelstiel–Wilson nodules | Diabetic nephropathy |
| Maltese cross | Nephrotic lipiduria |
| Tram-track GBM | MPGN |
| Basket-weave GBM | Alport |
| Cannonball metastases | Renal cell carcinoma (lung mets) |
| Staghorn calculus (Proteus) | Struvite (infection) stone |
| String of beads (angiography) | Fibromuscular dysplasia |
| Stauffer syndrome | Paraneoplastic RCC (hepatic dysfunction, no mets) |
| Cocoon / encased bowel | Encapsulating peritoneal sclerosis (PD) |

| Pair | Separator |
| --- | --- |
| Pre-renal vs ATN | FeNa <1% & urine osm >500 (pre-renal) vs FeNa >1–2%, isosthenuric, muddy-brown casts (ATN). If on diuretics → use FeUrea <35% |
| AKI vs CKD | Small echogenic kidneys, anaemia, ↑PO₄³⁻/↓Ca²⁺, old abnormal bloods → CKD |
| IgA nephropathy vs post-strep GN | Haematuria during infection + normal C3 (IgA) vs 1–2 weeks after + low C3 (post-strep) |
| Minimal change vs FSGS | Both nephrotic; MCD steroid-responsive, child, normal LM; FSGS steroid-resistant, segmental sclerosis, secondary causes |
| Anti-GBM vs ANCA (pulmonary–renal) | Linear IF + anti-GBM antibody vs pauci-immune + ANCA |
| Bartter vs Gitelman | Both hypokalaemic alkalosis/normal BP; Bartter = hyperCALCiuria, Gitelman = hypoCALCiuria + hypomagnesaemia |
| Liddle vs hyperaldosteronism | Both HTN + hypokalaemic alkalosis; Liddle = LOW aldosterone, responds to amiloride not spironolactone |
| HUS vs TTP | HUS = renal + child + diarrhoea; TTP = neuro + ADAMTS13, plasma exchange |
| Cranial vs nephrogenic DI | Cranial responds to desmopressin; nephrogenic does not |
| RTA type 1 vs 2 | Type 1 urine pH >5.5 + stones; Type 2 Fanconi + can acidify below threshold |
| RTA (any) vs diarrhoea (normal anion gap acidosis) | Urine anion gap: positive = RTA, negative = diarrhoea |
| Renal artery stenosis vs essential HTN | RAS: resistant HTN, flash pulmonary oedema, AKI on ACEi, asymmetric kidneys, bruit |
| CNI toxicity vs transplant rejection | Both raise creatinine in a graft — drug levels + biopsy distinguish |
| Glomerular vs urological haematuria | Dysmorphic RBCs + casts + protein = glomerular; isomorphic RBCs + clots = urological |
| Nephrotic vs nephritic | Protein-dominant, bland sediment (nephrotic) vs blood + RBC casts + HTN (nephritic) |
