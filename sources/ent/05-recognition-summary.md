# ENT Notes — Section 5: Recognition Summary and Confusable Pairs
*A lookup layer over Sections 1–4. Nothing new is taught here — this is for the last week before the paper.*

## 5.1 Syndrome recognition — one line in, one diagnosis out

| Presentation | Diagnosis |
|---|---|
| Two days of ear pain and discharge, exquisite pain on pulling the pinna | Otitis externa |
| Elderly diabetic, deep nocturnal otalgia, granulation on the canal floor, CN VII palsy | Necrotising (malignant) otitis externa — *Pseudomonas* |
| 14-month-old, fever, ear-tugging, bulging opaque immobile drum | Acute otitis media |
| Child with AOM, then postauricular swelling and the pinna pushed down and out | Acute mastoiditis |
| 5-year-old, inattentive, loud TV, dull retracted drum, type B tympanogram | Otitis media with effusion |
| Discharge through a perforation for over two weeks, conductive loss, no pain | Chronic suppurative otitis media |
| Scanty foul painless discharge, attic crust, drops don't work | Cholesteatoma |
| Woman in her thirties, worsening deafness in pregnancy, normal drum, hears better in noise | Otosclerosis (paracusis Willisii) |
| Bilateral symmetrical high-frequency loss, "I hear but can't understand" | Presbycusis |
| Shipyard worker, 4 kHz notch with recovery at 8 kHz | Noise-induced hearing loss |
| Unilateral deafness on waking, normal otoscopy, Weber to the good ear | Sudden sensorineural hearing loss |
| Unilateral progressive SNHL, poor discrimination, mild unsteadiness, reduced corneal reflex | Vestibular schwannoma |
| Bilateral vestibular schwannomas | Neurofibromatosis type 2 |
| Pulsatile tinnitus with a red mass behind the drum | Glomus tumour |
| Clear fluid from the ear after a head injury | CSF otorrhoea — skull base fracture |
| Lateral blow to the head, haemotympanum, conductive loss, delayed facial palsy | Longitudinal temporal bone fracture |
| Occipital blow, severe vertigo, dead ear, immediate complete facial palsy | Transverse temporal bone fracture |
| Ten-second spins on rolling over in bed, well between, no hearing loss | BPPV (posterior canal) |
| Continuous vertigo for three days after a viral illness, normal hearing, abnormal head impulse | Vestibular neuritis |
| The same, but with new unilateral hearing loss | Labyrinthitis — exclude AICA infarct |
| Continuous vertigo, normal head impulse, direction-changing nystagmus, cannot walk unaided | Posterior circulation stroke |
| Vertigo with ipsilateral facial pain loss, contralateral body pain loss, Horner's, hoarseness | Lateral medullary (Wallenberg) syndrome |
| Acute vertigo with ipsilateral deafness and facial weakness | AICA territory infarct |
| Recurrent vertigo 20 min–12 h with fluctuating low-frequency SNHL, tinnitus, fullness | Ménière's disease |
| Sudden drop to the ground without warning or LOC in known Ménière's | Tumarkin otolithic crisis |
| Recurrent vertigo 5 min–72 h with photophobia and a migraine history, normal audiogram | Vestibular migraine |
| Vertigo and oscillopsia on loud noise, autophony, hears own footsteps | Superior semicircular canal dehiscence |
| Non-spinning unsteadiness most days for months, worse upright and in supermarket aisles | PPPD |
| Stereotyped minutes-long vertigo attacks in a vasculopath with diplopia | Vertebrobasilar TIA |
| Child with a nosebleed from the anterior septum after picking | Anterior epistaxis — Little's area |
| Anticoagulated 75-year-old, blood from both nares and down the throat | Posterior epistaxis (sphenopalatine) |
| Adolescent male, recurrent unilateral epistaxis and unilateral obstruction | Juvenile nasopharyngeal angiofibroma |
| Ten days of blocked nose and facial pain that improved then worsened, fever 38.5 °C | Acute bacterial rhinosinusitis |
| Child, fever, swollen red lid after a URTI, full movements and normal acuity | Preseptal (periorbital) cellulitis |
| Same child, now proptosed with painful restricted movements and an RAPD | Orbital cellulitis |
| Bilateral eye signs, multiple cranial nerve palsies, swinging fever, meningism | Cavernous sinus thrombosis |
| Doughy forehead swelling in an adolescent with frontal sinusitis | Pott's puffy tumour |
| Twelve weeks of blockage and hyposmia with bilateral pale insensate masses | CRS with nasal polyps |
| Nasal polyps, asthma and bronchospasm after aspirin | Samter's triad / AERD |
| Sneezing, clear rhinorrhoea, pale boggy turbinates, allergic shiners each spring | Allergic rhinitis |
| Toddler with unilateral foul purulent nasal discharge for a week | Nasal foreign body |
| Boggy cherry-red septal swelling and obstruction after a punch | Septal haematoma |
| Neonate, cyclical cyanosis relieved by crying, catheter will not pass | Bilateral choanal atresia |
| Adult with unilateral serous otitis media, blood-stained postnasal discharge, upper neck node | Nasopharyngeal carcinoma |
| Abrupt fever, exudative tonsillitis, tender anterior nodes, no cough | Group A streptococcal pharyngitis |
| Adolescent, sore throat, posterior nodes, splenomegaly, rash after amoxicillin | Infectious mononucleosis |
| Unilateral throat pain, trismus, hot-potato voice, uvula pushed across | Peritonsillar abscess (quinsy) |
| Adult, severe odynophagia and drooling with a near-normal oropharynx | Adult epiglottitis |
| Bilateral woody floor-of-mouth swelling, tongue pushed up, after dental sepsis | Ludwig's angina |
| Child <5, fever, torticollis, neck held extended, widened prevertebral soft tissues | Retropharyngeal abscess |
| Sore throat, then rigors, tender sternocleidomastoid, cavitating lung lesions | Lemierre's syndrome |

## 5.2 Signature findings — the single fact that clinches it

| Finding | What it means |
|---|---|
| Weber lateralising to the deaf ear | Conductive loss on that side |
| Weber lateralising away from the deaf ear, Rinne positive both sides | Sensorineural loss |
| Rinne "negative" but Weber to the *other* ear | False-negative Rinne — dead ear; mask and re-test |
| Air–bone gap with a bone-conduction dip at 2 kHz | Carhart notch — otosclerosis |
| Type B tympanogram, normal canal volume | Middle ear effusion |
| Type B tympanogram, large canal volume | Perforation or patent grommet |
| Normal head impulse test in acute vestibular syndrome | Central lesion — stroke |
| Direction-changing, vertical or pure torsional nystagmus | Central lesion |
| Unilateral serous otitis media in an adult | Nasopharyngeal carcinoma until the nasopharynx is examined |
| Uvular deviation with trismus | Peritonsillar abscess |
| Widespread maculopapular rash after amoxicillin | Infectious mononucleosis — not penicillin allergy |
| Attic (pars flaccida) perforation with foul discharge | Cholesteatoma |
| Granulation tissue at the bony–cartilaginous junction | Necrotising otitis externa |
| Facial nerve palsy with a parotid mass | Parotid malignancy |
| Unilateral nasal obstruction with epistaxis in an adolescent male | JNA — image, never biopsy |
| Hoarseness beyond three weeks in a smoker | Laryngoscopy for laryngeal SCC |
| Proptosis, painful eye movements, reduced acuity, RAPD | Postseptal (orbital) cellulitis |
| Pinna displaced down and out with loss of the postauricular crease | Acute mastoiditis |
| Fluctuating low-frequency SNHL documented on audiogram | Ménière's disease |
| Vertigo triggered by loud noise with intact acoustic reflexes | Superior canal dehiscence (Tullio) |
| Clear rhinorrhoea or otorrhoea after head trauma | CSF leak — skull base fracture |
| A unilateral nasal polyp | Not CRSwNP — image and biopsy |
| Inability to stand or walk unaided in acute vertigo | Cerebellar stroke |
| Unilateral otalgia with a completely normal ear | Referred pain via CN V, IX, X — examine pharynx/larynx |
| Quietening stridor with rising distress and falling air entry | Airway closing — call for help now |

## 5.3 Confusable pairs

| Pair | How to tell them apart |
|---|---|
| Conductive vs sensorineural loss | Weber goes **to** the conductive ear, **away from** the sensorineural ear; Rinne negative (BC > AC) and an air–bone gap only in conductive loss |
| Otitis externa vs otitis media | Tragal/pinna tenderness with canal oedema = externa; bulging immobile drum with fever = media. Externa is treated topically, media systemically |
| Acute otitis media vs otitis media with effusion | AOM: acute pain, fever, bulging opaque drum. OME: painless, dull retracted drum, hearing loss and inattention, type B tympanogram, no antibiotics |
| Cholesteatoma vs simple chronic perforation | Cholesteatoma: attic/marginal defect, scanty foul painless discharge, granulation, drops fail, needs surgery. CSOM: central pars tensa ("safe") perforation, mucopurulent discharge drying with aural toilet plus ciprofloxacin |
| Sudden SNHL vs sudden conductive loss (wax/effusion) | Both feel blocked. Wax/effusion is visible, Weber **to** the bad ear; sudden SNHL has a normal drum, Weber to the **good** ear — steroids urgently |
| BPPV vs vestibular neuritis | BPPV: seconds, positionally triggered, symptom-free between, Dix–Hallpike positive. Neuritis: continuous for days, worse on movement but not caused by it, spontaneous nystagmus, abnormal head impulse |
| BPPV vs Ménière's | Both episodic — duration decides: seconds and positional (BPPV) versus 20 min–12 h with tinnitus, fullness and fluctuating SNHL (Ménière's) |
| Ménière's vs vestibular migraine | Ménière's needs documented low-to-mid frequency SNHL; VM has a normal audiogram, migrainous features and visual-motion sensitivity, attacks 5 min–72 h |
| Peripheral vs central acute vestibular syndrome (HINTS) | Peripheral = abnormal head impulse + unidirectional fixation-suppressed nystagmus + no skew. Any one of: normal head impulse, direction-changing/vertical nystagmus, or skew → central. HINTS applies only to ongoing AVS |
| Vestibular neuritis vs labyrinthitis | Identical, except labyrinthitis adds hearing loss/tinnitus. But new deafness in AVS is also the AICA infarct pattern — HINTS-plus; do not assume benign |
| Vestibular schwannoma vs presbycusis | Presbycusis is bilateral, symmetrical, gradual. Schwannoma is asymmetric with discrimination worse than the PTA predicts, unilateral tinnitus, mild imbalance — MRI IAM |
| Viral vs bacterial rhinosinusitis | Viral peaks then improves by day 5–7. Bacterial suggested by ≥3 of: fever >38 °C, double sickening, unilateral disease, severe pain, raised ESR/CRP. Purulent green mucus alone means nothing |
| Preseptal vs orbital cellulitis | Preseptal: lid swelling with a normal globe — full movements, normal acuity, no proptosis. Orbital: proptosis, painful/restricted movements, reduced acuity, RAPD, chemosis → CT and IV antibiotics |
| Allergic vs vasomotor rhinitis vs CRS | AR: sneezing, itch, clear rhinorrhoea, pale boggy turbinates, allergen triggers. Vasomotor: obstruction and rhinorrhoea on temperature, odours, alcohol — no itch, sneeze or allergen link. CRS: ≥12 weeks plus objective endoscopic/CT findings |
| Nasal polyps vs a unilateral nasal mass | Polyps are bilateral, pale, insensate, painless, with hyposmia. Anything unilateral — bleeding, pain, numbness, epiphora — is neoplasm until imaged and biopsied (in a child exclude encephalocoele) |
| Anterior vs posterior epistaxis | Anterior: young, unilateral drip, visible point at Little's area, controlled by pressure ± cautery. Posterior: older/arteriopathic, both nares and down the throat, fails first aid — tamponade, SPA ligation or embolisation |
| Streptococcal pharyngitis vs infectious mononucleosis | GAS: abrupt fever, exudate, tender **anterior** nodes, no cough. IM: prolonged fatigue, **posterior**/generalised nodes, palatal petechiae, hepatosplenomegaly, atypical lymphocytes, rash if given amoxicillin |
| Quinsy vs simple tonsillitis | Quinsy is unilateral with trismus, hot-potato voice, drooling, peritonsillar bulge and uvular deviation, and needs drainage plus antibiotics. Tonsillitis is symmetrical without trismus |
| Adult epiglottitis vs severe pharyngitis | Epiglottitis: symptoms out of proportion to a near-normal oropharynx, drooling, muffled voice, tripod posture, stridor late. Do not use a spatula, do not lie flat — senior airway team |
| Benign vs sinister neck lump | Benign: <20 yrs, short history, tender, mobile, resolves. Sinister: >40 yrs, >3 weeks, hard, fixed, >2 cm, supraclavicular, or mucosal red flags — USg-FNAC, never excision |
| Pleomorphic adenoma vs parotid malignancy | Adenoma: slow, painless, mobile, nerve intact. Pain, fixity, rapid growth, skin involvement or **facial nerve palsy** means malignancy |
| Thyroglossal cyst vs branchial cyst | Thyroglossal: **midline**, rises on tongue protrusion and swallowing. Branchial: **lateral**, anterior to the upper third of sternocleidomastoid, young adult, may present infected |

## 5.4 The must-not-miss list

| Emergency / red flag | Time-critical action |
|---|---|
| Sudden SNHL | Same/next-day audiogram; high-dose oral steroids ASAP, ideally within 14 days; MRI IAM |
| Central cause of acute vertigo (posterior circulation stroke) | HINTS + gait; MRI-DWI (not CT); acute stroke pathway |
| Necrotising otitis externa | Admit; biopsy granulation; prolonged systemic antipseudomonal therapy; glycaemic control |
| Mastoiditis / intracranial complications of AOM | Admit, IV antibiotics, ENT, CT if abscess; myringotomy ± mastoidectomy |
| Orbital cellulitis / cavernous sinus thrombosis | Urgent contrast CT (MRI/MRV for CST), IV ceftriaxone, ENT + ophthalmology, drain abscess |
| Adult epiglottitis / Ludwig's angina | No spatula, no lying flat; upright, oxygen; senior ENT + anaesthetics, surgical airway available |
| Post-tonsillectomy haemorrhage | Every bleed is an emergency — IV access, group and hold, NBM, ENT; theatre if active |
| Juvenile nasopharyngeal angiofibroma | Contrast imaging and tertiary referral — **never** biopsy |
| Septal haematoma | Urgent incision, drainage and quilting — otherwise cartilage necrosis and saddle nose |
| Unexplained neck lump >40 yrs | Ultrasound-guided FNA, not excisional biopsy; head and neck MDT |
| Hoarseness >3 weeks | Laryngoscopy — no PPI trial first |
| Unilateral middle ear effusion in an adult | Nasoendoscopy of the nasopharynx (NPC) |
| Airway obstruction / stridor | Minimal handling, oxygen, senior airway team; quietening stridor with rising distress = closing airway |

## ⚠ Inconsistencies found in Sections 1–4

- **CN V signs in vestibular schwannoma.** Section 1.5 calls CN V/VII signs **late**; Section 2.8 calls a reduced corneal reflex a classic **early** CPA sign. 5.1/5.3 above avoid committing to timing — decide which to memorise.
- **Topical decongestant duration.** Section 3.3's short version says **≤5 days**; its own management table, the 3.6 ladder and the Section 3 rapid-recall table all say **3–5 days**. 5.5 quotes 3–5 days.
- **Antibiotic threshold in ARS.** Section 3.3 uses "beyond ~10 days without improvement" in one paragraph and ">7–10 days" in the next.
