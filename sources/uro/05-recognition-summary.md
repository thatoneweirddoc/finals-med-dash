# Urology Notes — Section 5: Recognition Summary and Confusable Pairs
*A lookup layer over Sections 1–4. Nothing new is taught here — this is for the last week before the paper.*

## 5.1 Syndrome recognition — one line in, one diagnosis out

| Presentation | Diagnosis |
|---|---|
| Painless visible haematuria, 68-y-old smoker, single episode | Bladder urothelial carcinoma — CT urography **plus** cystoscopy |
| Visible haematuria with a positive urine culture, age 65 | Still full workup — a cultured UTI never excuses imaging + cystoscopy |
| Visible haematuria in a man on a DOAC | Investigate — anticoagulation unmasks lesions, does not explain them |
| Recurrent "culture-negative UTIs", urgency, sterile pyuria, older smoker, normal-looking bladder | Bladder CIS — blue-light cystoscopy, mapping biopsies, cytology |
| TURBT specimen containing no detrusor muscle | Unstageable — re-TURBT |
| Bladder cancer in a migrant with schistosomiasis | Squamous cell carcinoma |
| T1 high-grade tumour with CIS | Re-TURBT then BCG induction + maintenance 1–3 years |
| Fever, hepatitis and miliary shadowing weeks after BCG | BCGosis — antituberculous therapy |
| T2 disease, fit, adequate eGFR | Neoadjuvant cisplatin chemo → radical cystectomy |
| Incidental 3 cm enhancing renal mass on CT | RCC — partial (nephron-sparing) nephrectomy |
| Bilateral multifocal clear cell RCC, haemangioblastoma, phaeochromocytoma | Von Hippel–Lindau |
| Filling defect in the renal pelvis on delayed CT urography, family history of bowel and endometrial cancer | Upper tract urothelial carcinoma, Lynch — nephroureterectomy with bladder cuff |
| PSA 4.2 at 60, PI-RADS 4 lesion | Targeted transperineal biopsy |
| PSA 3.4, PI-RADS 3, PSA density 0.09 | Monitor — biopsy only if density ≥0.15 |
| Back pain, sclerotic vertebrae, ALP up, calcium normal | Metastatic prostate cancer |
| New metastatic prostate cancer with impending cord compression | GnRH **antagonist** or antiandrogen cover — avoid agonist flare |
| Older man, urgency and small-volume frequency, normal stream, PVR 30 mL | Overactive bladder |
| Older man, hesitancy, weak stream, terminal dribble over years, IPSS 22 | BPH with outflow obstruction |
| Man on tamsulosin with cataract surgery booked | Intraoperative floppy iris syndrome — warn the ophthalmologist |
| Confusion, hyponatraemia, visual disturbance mid-TURP | TUR syndrome (glycine, monopolar) |
| Young man, spraying stream, prior urethritis, no alpha-blocker response | Urethral stricture |
| Nocturia with snoring, witnessed apnoeas, obesity | Nocturnal polyuria from OSA — not the prostate |
| Nocturia with large-volume voids day and night, thirst, weight loss | Global polyuria — diabetes mellitus / DI |
| Agonising inability to void, tender palpable bladder, relief on catheter | Acute urinary retention |
| Painless retention, nocturnal enuresis, creatinine 240, bilateral hydronephrosis | High-pressure chronic retention |
| Painless retention with back pain, saddle numbness, lax anal tone | Cauda equina — immediate whole-spine MRI |
| T6 paraplegic, blocked catheter, headache, BP 210/120 | Autonomic dysreflexia — sit up, relieve the trigger |
| Woman leaking on coughing and lifting, no urgency | Stress incontinence — supervised pelvic floor training |
| Dribbling incontinence with PVR 450 mL | Overflow — drain/CISC, never an antimuscarinic |
| 16-y-old woken by severe testicular pain, vomiting, high-riding transverse testis, absent cremasteric reflex | Testicular torsion — theatre, no imaging |
| 9-y-old, 2 days upper-pole tenderness, 4 mm blue nodule, well | Torted appendix testis — conservative |
| Newborn with a firm, non-tender, discoloured hemiscrotum | Extravaginal perinatal torsion |
| Recurrent brief self-resolving episodes of severe testicular pain | Intermittent torsion — elective bilateral orchidopexy |
| 24-y-old, days of building pain, dysuria, discharge, fever | Sexually acquired epididymo-orchitis |
| 65-y-old with an IDC, gradual scrotal pain, coliforms on MSU | Enteric epididymo-orchitis — investigate the outflow problem |
| Post-pubertal male, parotitis 6 days earlier, orchitis | Mumps orchitis — supportive, notifiable |
| Diabetic, perineal pain out of proportion, crepitus, dusky skin, septic | Fournier's gangrene |
| Firm intratesticular mass at 28, hypoechoic on ultrasound | Germ cell tumour — radical **inguinal** orchidectomy, never scrotal biopsy |
| Tumour reported as "seminoma" but AFP 300 | Manage as non-seminomatous GCT |
| Bilateral testicular masses in a 70-y-old | Testicular lymphoma |
| "Bag of worms" emptying supine, left side, subfertility | Varicocele |
| Cystic nodule above and separate from the testis, transilluminates | Epididymal cyst / spermatocele |
| Smooth fluctuant swelling, testis impalpable within, transilluminates, age 25 | Hydrocele — ultrasound to exclude tumour |
| Scrotal swelling you cannot get above, cough impulse | Inguinoscrotal hernia |
| Writhing loin-to-groin pain, vomiting, microscopic haematuria | Ureteric colic — low-dose CT KUB, NSAID first |
| Staghorn calculus, urine pH 7.5, *Proteus* | Struvite infection stone — complete clearance |
| Recurrent radiolucent stones, gout, urine pH 5.0 | Uric acid stones — alkalinise |
| Recurrent stones since childhood, family history, faint ground-glass stones | Cystinuria |
| Stones after bariatric surgery or in Crohn's | Enteric hyperoxaluria |
| Ureteric stone **plus** fever, rigors, lactate 4 | Infected obstructed kidney — decompress within hours |
| 72-y-old "renal colic" with hypotension and a pulsatile mass | Leaking AAA |
| Diabetic, septic, gas in the renal parenchyma on CT | Emphysematous pyelonephritis |
| Prolonged fever, weight loss, flank mass after treated pyelonephritis | Perinephric abscess — drainage |
| Young woman, dysuria/frequency/urgency, no discharge | Uncomplicated cystitis — nitrofurantoin 5 days |
| Asymptomatic pregnant woman, MSU 10⁵ *E. coli* at 14 weeks | Treat 5 days, test of cure |
| Aged-care resident, cloudy malodorous urine, afebrile, catheter in situ | Colonisation — do not culture, do not treat |
| Fever, rigors, loin pain, costovertebral angle tenderness | Acute pyelonephritis |
| Febrile man, perineal pain, exquisitely tender boggy prostate | Acute bacterial prostatitis — no massage, no nitrofurantoin |
| 3 months of perineal pain, negative cultures, afebrile | CP/CPPS (NIH III) — multimodal, not more antibiotics |
| AKI, anuria, bland urinalysis, known pelvic malignancy | Obstructive uropathy — renal tract ultrasound |

## 5.2 Signature findings — the single fact that clinches it

| Finding | What it means |
|---|---|
| Painless visible haematuria | Urothelial malignancy until the workup says otherwise |
| >3 RBC/hpf on microscopy | Defines non-visible haematuria (dipstick alone does not) |
| Dipstick blood positive, bland microscopy | Myoglobin or free haemoglobin |
| Red-cell casts / dysmorphic RBCs / proteinuria | Glomerular — refer renal |
| Sterile pyuria | CIS, chlamydia, renal TB, stone, tumour, interstitial nephritis, partly treated UTI |
| Deranged LFTs with a renal mass and no liver mets | Stauffer syndrome |
| Raised Hb/Hct with a renal mass | Paraneoplastic erythropoietin |
| High calcium with suppressed PTH and a renal mass | PTHrP secretion |
| Non-decompressing or right-sided varicocele | Venous obstruction — image the retroperitoneum |
| Enhancement >15–20 HU in a renal lesion | Solid enhancing mass = RCC |
| Cannonball lung lesions, lytic hypervascular bone mets | Metastatic RCC |
| Osteoblastic bone metastases, ALP up, calcium normal | Prostate cancer via Batson's plexus |
| AFP raised in a testicular tumour | Non-seminomatous elements — never pure seminoma |
| Very high β-hCG with gynaecomastia ± thyrotoxicosis | Choriocarcinoma |
| Absent cremasteric reflex + high-riding transverse testis | Torsion (a present reflex does not exclude it) |
| Normal Doppler flow with a convincing torsion history | Still torsion — explore |
| Blue dot at the upper pole | Torted appendix testis |
| Pain out of proportion to visible signs ± crepitus | Necrotising fasciitis / Fournier's |
| Vomiting with acute scrotal pain | Shifts strongly towards torsion |
| Painless retention with renal failure and bilateral hydronephrosis | High-pressure chronic retention |
| Nocturnal enuresis in an older man | High-pressure chronic retention until disproved |
| Lax anal tone / saddle anaesthesia | Cauda equina — MRI now |
| Urine output ≥200 mL/h for 2 consecutive hours after decompression | Post-obstructive diuresis |
| Gas in the renal parenchyma on CT | Emphysematous pyelonephritis (>90% diabetic) |
| Alkaline urine pH >7 with a staghorn | Urease producer — struvite |
| Radiolucent on KUB but visible on CT | Uric acid or cystine |
| PSA halved on a 5-ARI | Expected — double it; any rise is suspicious |
| Bland urinalysis in a febrile obstructed patient | The obstructed side cannot drain — does not exclude pyonephrosis |

## 5.3 Confusable pairs

| Pair | How to tell them apart |
|---|---|
| Torsion vs epididymo-orchitis | Torsion: instantaneous onset, vomiting, high-riding transverse testis, absent cremasteric reflex, normal urinalysis, afebrile → theatre. EO: builds over days, dysuria/discharge/fever, pyuria, normal lie, reflex preserved → antibiotics. Prehn's sign decides nothing |
| Torsion vs torted appendix testis | Whole testis exquisitely tender with abnormal lie vs a 3–5 mm tender upper-pole nodule and blue dot, normal lie, well child aged 7–12 |
| Seminoma vs NSGCT | Seminoma: later peak, **AFP never raised**, β-hCG up to 30%, orderly nodal spread, radiosensitive. NSGCT: younger, AFP/β-hCG raised, early haematogenous spread, chemosensitive (BEP), not radiosensitive |
| Hydrocele vs varicocele vs epididymal cyst | Hydrocele transilluminates, testis impalpable within. Varicocele does **not** transilluminate, worse standing/Valsalva, empties supine. Epididymal cyst transilluminates and is **separate from and above** the testis |
| BPH vs prostate cancer | BPH: smooth, symmetrical, rubbery, sulcus preserved, years of voiding symptoms. Cancer: hard, craggy, asymmetric, sulcus lost — refer regardless of PSA; usually asymptomatic when curable, so LUTS discriminates poorly. Suspicious extras: bone pain, weight loss, haematuria, renal failure |
| Storage vs voiding LUTS | Storage (frequency, urgency, nocturia, urge leak) = the bladder. Voiding (hesitancy, weak stream, straining, terminal dribble) = obstruction or a weak detrusor. Obstruction causes storage symptoms *secondarily* via detrusor hypertrophy |
| Overactive bladder vs BPH obstruction | Urgency dominant, normal stream, low PVR = OAB. Voiding-predominant, raised PVR, large gland = obstruction. **PVR decides** — an antimuscarinic in an obstructed man precipitates retention |
| Acute vs chronic retention | Acute: agonising, tender palpable bladder, immediate relief, normal creatinine. Chronic: painless, very large volume, enuresis, ± hydronephrosis and renal impairment. High- vs low-pressure chronic retention is decided by upper tracts and creatinine |
| Renal colic vs pyelonephritis vs ruptured AAA | Colic: writhing, afebrile, haematuria. Pyelonephritis: fever, rigors, CVA tenderness, pyuria. AAA: >50 y, hypotension, pulsatile mass — exclude before anchoring on stone. Colic **plus** fever is a third entity: infected obstructed kidney |
| Uncomplicated vs complicated UTI | Uncomplicated = cystitis in a non-pregnant, non-immunocompromised woman with a normal tract. Complicated = men, pregnancy, catheter, stones, obstruction, transplant, instrumentation, poorly controlled diabetes → culture, longer course, find the cause |
| Asymptomatic bacteriuria you treat vs do not | Treat **only** in pregnancy and before an invasive urological procedure breaching mucosa. Do not treat the elderly, diabetics, catheterised patients or aged-care residents |
| Cystitis vs pyelonephritis vs prostatitis | Cystitis: dysuria/frequency, afebrile, 5 days nitrofurantoin. Pyelonephritis: fever, rigors, loin pain, 10–14 days, **nitrofurantoin useless**. Prostatitis: fever, perineal pain, boggy tender prostate, 2–4 weeks with a prostate-penetrating agent, no massage |
| RCC vs upper tract UC vs angiomyolipoma | RCC: enhancing solid **parenchymal** mass → partial/radical nephrectomy. UTUC: **filling defect in the collecting system**, Lynch/aristolochic acid → nephroureterectomy with bladder cuff. AML: macroscopic fat, tuberous sclerosis, benign |
| Bladder cancer vs radiation cystitis | Both give haematuria and irritative symptoms after pelvic radiotherapy — but radiotherapy is itself a risk factor for urothelial cancer, so the history never excuses skipping cystoscopy |
| Alpha-blocker vs 5-alpha-reductase inhibitor | Alpha-blocker: relief in days–2 weeks, any gland size; postural hypotension, retrograde ejaculation, IOFS. 5-ARI: shrinks the gland, needs 3–6 months, only for larger glands, **halves PSA**, teratogenic |
| Stress vs urge incontinence | Stress: leak *at the moment of* cough/lift, no urgency, parity/menopause or post-prostatectomy → pelvic floor training first. Urge: leak *preceded by* urgency, triggered by key-in-door → bladder training then mirabegron/antimuscarinic |
| Testicular cancer vs epididymo-orchitis | Cancer: painless, firm, **intratesticular**, afebrile. EO: painful, tender, epididymal first, febrile, pyuria. A mass persisting after antibiotics, or failure to settle by 72 h, means image — tumours masquerade as epididymo-orchitis |
| Fournier's vs simple scrotal cellulitis | Fournier's: pain grossly out of proportion, systemic toxicity, crepitus, dusky skin, bullae, skin anaesthesia, diabetic/immunosuppressed → theatre. Cellulitis: pain matches the erythema, responds to antibiotics. CT must not delay theatre |

## 5.4 The must-not-miss list

| Emergency | Time-critical action |
|---|---|
| **Testicular torsion** | Straight to theatre — salvage near-universal <6 h, falling by 12–24 h, rare beyond 24 h. Imaging must not delay. Bilateral orchidopexy |
| **Infected obstructed kidney** | Fever + obstruction = decompress within **hours** (stent or nephrostomy) plus IV antibiotics after cultures; defer stone treatment |
| **Fournier's gangrene** | Resuscitate, broad-spectrum IV antibiotics ± clindamycin, **urgent radical debridement**, planned re-look at 24–48 h. Antibiotics never substitute for the knife |
| **High-pressure chronic retention with renal failure** | Catheterise and drain completely; monitor for post-obstructive diuresis; correct electrolytes; function usually recovers |
| **Cauda equina syndrome** | Senior review + urgent **whole-spine MRI**. Retention is a *late* sign and a normal PVR does not exclude it; add corticosteroid if metastatic cord compression |
| **Priapism** | **Ischaemic** (low-flow): painful, rigid, no flow — a compartment syndrome; aspirate ± intracavernosal phenylephrine, treat by **4 h**; prolonged episodes cause fibrosis and ED. **Non-ischaemic** (high-flow, post-traumatic): painless, partly rigid, not an emergency — observe/embolise |
| **Paraphimosis** | Foreskin trapped behind the glans with constriction and oedema — reduce the same hour (compression, ice, local anaesthetic); dorsal slit if reduction fails |
| **Penile fracture** | Tunica albuginea tear during intercourse — crack, detumescence, aubergine deformity. Urgent exploration and repair; retrograde urethrogram if blood at the meatus |
| **Post-obstructive diuresis** | Hourly output, daily weights, frequent electrolytes; replace only part of losses (5.5) — replacing 100% perpetuates it |

|---|---|

| Repeat MSU after menses / exercise | ≥7 days / 48–72 h |
| Low-risk NVH profile | <50 y, <10 pack-years, <10 RBC/hpf; repeat urinalysis within 6 months |
| Referral categories | Cat 1 ≤30 days (visible haematuria); Cat 2 ≤90 days |

| Re-TURBT | 2–6 weeks |
| BCG maintenance | 1 year (intermediate) vs 1–3 years (high risk) |
| Bladder cancer proportions | >90% urothelial; ~75% non-muscle-invasive; smoking ~50%; painless VH ~80% |
| Neoadjuvant chemo in MIBC | ~5% absolute 5-year OS gain |

## ⚠ Inconsistencies found in Sections 1–4

1. **How much to replace in post-obstructive diuresis.** Section 2.4 says "no more than about 75% of the preceding hour's output"; Section 4.8 says "roughly 50–75% of losses". Same intent (deliberate mild negative balance), but the two files should carry one figure. 5.5 quotes the Section 4 range.
2. **POD monitoring interval.** Section 2.4 says electrolytes and creatinine "every 8–24 h"; Section 4.8 says UEC and magnesium "at least 12-hourly".
3. **Age at which PSA is offered to higher-risk men.** Section 1.5 (2026 guideline) says offer 2-yearly **from age 45**; Section 2.2, quoting the RACGP Red Book 2024, says from 50, or **40–45** with significant family history. Section 1 is the safer answer for the paper, but the starting ages differ.
